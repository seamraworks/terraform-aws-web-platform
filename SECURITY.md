# Security

Report vulnerabilities privately through this repository's GitHub security
advisory feature. Do not post credentials, comment exports or private user data
in public issues.

Keep state and SSM access restricted, preserve origin/authentication secrets,
and use only the dedicated host IAM identity on Lightsail. The runtime assumes
a dedicated host. Public recovery and automation credentials must remain blocked.
Provider failures retain content; changing providers does not grant them deletion
or account-blocking access.
